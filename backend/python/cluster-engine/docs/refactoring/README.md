## 首要结论

- 当前“训练”主要是 Optuna 聚类超参数搜索，不是 BGE 训练。
- 每个请求整批重新聚类。簇 ID 不跨运行稳定，拆批不等价于全量聚类。
- 旧算法问题保留在 `legacy-v1`，不会借重构之名修改实验结果。
- 缺少历史向量、索引和本地权重，不能宣称论文指标已复现。测试基线标为 `current-environment`。
- 源码中的旧远程凭证已移除；外部提供方的凭证撤销/轮换仍需账号持有人执行。本轮未调用真实嵌入服务。
