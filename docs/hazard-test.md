# 隐患测试

入口为侧栏“隐患测试”，路由 `#/hazard-test`。启动方式保持 `npm run dev`；已运行的 API 需要重启才能加载新增路由。未添加第三方依赖。

## 数据字段与评测范围

默认文件为 `datas/test/隐患抽样_抽样50条.csv`，实际包含 50 条、29 列：A 级 0 条，B 级 10 条，C/D 级各 20 条。

| 用途 | 真实字段 | 处理 |
| --- | --- | --- |
| Agent 输入 | 隐患描述、隐患分类 | 复用已有文本评测方式，描述必填，分类可选。移除描述内明确的最终等级声明，保留 B 级作业票等现场事实 |
| 标准答案 | 隐患级别 | 归一化为 A/B/C/D，接受大小写、全角和“级”后缀；空值保留但不计分，其他值拒绝上传 |
| 人工定级依据 | A/B级判定标准 | 仅供详情核对，不传入 Agent |
| 定位和追踪 | 隐患单号、项目、排查类型、作业区域、责任单位 | 原样保留展示，不作为人工答案 |
| 人员、流程、时间 | 整改责任人、整改期限、整改时间、检查人、检查日期、检查时间、流程环节、所属业务版块一级、所属业务版块二级、创建人、是否按期关闭、关闭日期、关闭时间、验证人、验证日期、验证时间、状态 | 原样保留，不传入 Agent，避免事后信息影响定级 |
| 图片追踪 | 主信息图片1、主信息图片2、图片文件 | 原样保留；本功能测文本定级，不读取本地图片路径或远程图片 |

项目没有现成的运行时 Excel 解析依赖，本功能支持 CSV。上传限制为 5MB、500 条，使用现有 CSV 解析器的新增严格校验选项，支持 BOM、引号、转义双引号、多行字段及 UTF-8/GB18030（兼容 GBK）编码。必要表头是“隐患描述”“隐患级别”；空文件、缺列、重名表头、列数错位、未闭合引号、无效等级或空描述均返回明确错误。

## 比对和统计

CSV 只有一个互斥分类“隐患级别”，没有四个独立人工答案。Agent 最终 `hazards[0].grade`（已经过现有定级护栏）与此字段比较，模型候选等级和风险追踪保存在完整结果中。

- 总体准确率：最终等级完全一致的数量 / 成功且有标准答案的数量 × 100%。
- A/B/C/D 准确率：分别判断“属于 / 不属于该等级”是否一致，包含正确排除的负样本。例如 B→C 时 A、D 正确，B、C 错误，总体错误。
- 各等级样本命中率：标准答案属于该等级且判断正确的数量 / 成功且标准答案属于该等级的数量 × 100%。默认集没有 A 级正样本，A 级样本命中率显示“—”。
- 空标准答案、执行失败、尚未完成均排除在准确率分母外；没有有效样本时显示“—”，不会显示虚假的 0% 或 100%。
- 执行成功数量与判断正确数量分开统计。原 Agent 的失败兜底等级不作为有效预测；此类记录标记执行失败并保留完整结果、原始输出和异常原因。有效但需人工复核的暂定等级正常比对，详情提示复核状态。

## 执行与接口

`server/testing/` 负责数据集、比较、统计、任务及导出；`server/http/hazard-test.routes.ts` 遵循现有 `{ data }` / `{ error, code }` 约定并位于原认证门禁之后。缓存按登录用户隔离；当前入口禁用登录时沿用项目的 `anonymous-demo` 共享范围。

| 接口 | 用途 |
| --- | --- |
| GET `/api/hazard-tests/datasets/default` | 读取默认文件并返回数据集元信息 |
| POST `/api/hazard-tests/datasets` | multipart `file` 上传 CSV |
| POST `/api/hazard-tests/jobs` | JSON `{ datasetId, concurrency?, maxOutputTokens? }` 创建测试任务 |
| GET `/api/hazard-tests/jobs/latest` | 恢复该用户最近任务 |
| GET `/api/hazard-tests/jobs/:id` | 进度、统计和逐条结果 |
| POST `/api/hazard-tests/jobs/:id/stop` | 等待所有正在执行的条目完成，不再领取待执行项 |
| GET `/api/hazard-tests/jobs/:id/errors.csv` | 导出错误和执行失败记录，含完整原始数据、模型正文及 Agent 结果 |

Agent Runtime 和原图片工作流增加可选文本候选入口，文本跳过视觉调用，后续检索、规则、上下文、推理、Schema 验证、定级护栏、结果装配、Token 和运行追踪均复用。原图片请求不传该参数，保持原有行为。公开模型原文通过内部回调保存完整内容；运行时原有 UI 流式正文长度上限保持原值。

任务支持 1–16 个并发 worker（页面“并发数 / 线程”），默认 1，控制同时执行的条目数量，不创建操作系统线程。每项只领取一次，结果保留原 CSV 顺序；一条失败继续后续条目。同一用户运行中重复开始同一数据集返回已有任务及其原设置；不同数据集返回冲突。前端禁用重复提交，每 1.5 秒串行轮询；切换页面、刷新或客户端断开不终止后端任务。停止后不再领取待执行项，等待所有在途条目结束，不强制中断已有模型请求。

“单条输出上限”接受 6400–32000 的整数，默认仍为原来的 6400，仅用于文本测试的风险推理调用，原图片分析和摘要调用预算不变。启动时将并发数和输出上限快照保存在任务 `options` 中，执行中不可修改，刷新恢复同一设置。接口省略参数兼容原有串行行为，非法类型、非整数及越界参数返回 400。

`模型接口返回空内容（finish_reason=length, ...）` 表明服务以长度限制结束生成，但没有返回可用正文；`reasoning_content=absent` 在现有流式诊断中不能证明模型没有内部推理。提高并发不会增大单条输出预算。可以提高单条输出上限后重测，但仍受供应商输出、上下文和限流约束，不能保证消除空输出；原 Provider 的有界重试和失败统计方式保持不变。

缓存为有界进程内存，最多 12 个数据集和 12 个任务，24 小时后过期；容量满时淘汰最早的非运行记录，运行任务不淘汰。服务重启不保留缓存；刷新找回最近任务，过期后需要重新加载默认数据或上传。需要长期留存时可导出错误 CSV。CSV 导出对公式前缀加引号保护，完整原始数据另以 JSON 列保留。

## 验证

运行 `npm run test:hazard`、`npm run test:grading`、`npm test`、`npm run build`。

新增自动测试覆盖真实 50 条数据、字段映射、CSV 异常、无标准答案、比较分母、单条异常、兜底排除、重复任务、停止、用户隔离、完整原文、上传及导出 API。50 条批量自动测试使用真实 Runtime/检索/定级护栏与注入的确定性 Provider，结果仅用于验证实现，不代表真实模型准确率。

2026-09-11 验证记录：`npm test` 71 项通过，`npm run test:grading` 14 项通过，生产构建通过。隔离浏览器验收覆盖默认 50 条、进度、重复提交禁用、刷新恢复、各类筛选、详情、下载、错误文件提示、自定义数据、停止和 1100px 布局，未发现浏览器运行异常。

真实接口冒烟测试发现当前已有配置的模型名 `DeepSeek-V4.1-Flash` 被网关以 400 拒绝；该记录正确标记失败，统计分母为 0。使用同一连接配置、通过临时 Provider 覆盖模型名为网关支持的 `deepseek-flash` 后，单条真实调用成功（标准 D、最终 C，差异 C/D，完整公开原文 2092 字符）。这次隔离验证未修改现有模型配置，也未对 50 条执行真实模型全量评测。实际使用前应在“模型配置”选择网关支持的 API 模型名；文本模型是否支持原图片功能仍取决于原供应商配置。
